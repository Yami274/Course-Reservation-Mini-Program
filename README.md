# 项目概述

本项目为少儿美术/画室相关的课程与运营管理系统，包含小程序端、后台管理端与后端服务三部分。面向家长与学生提供课程浏览、下单、收藏、通知等功能；面向机构管理人员提供课程、订单、老师、学生、场地、通知等运营管理能力。

## 主要模块

- applet：小程序端（uni-app），面向家长/学生的课程与订单体验。
- web-admin：后台管理前端（Vite + Vue），面向机构管理人员的运营管理界面。
- backend：后端服务（Node.js），提供认证、课程、订单、通知、学生、老师等业务接口。

## 目录结构

- applet/：小程序端源码
- web-admin/：后台管理前端源码
- backend/：后端服务源码

## 适用场景

- 线下画室/少儿美术机构课程展示与招生
- 课程预约、下单、通知推送与学员管理
- 管理端课程、订单、场地、老师与通知等运营管理
