# 安然画室 · 讲师工作台

Vue 3 + Vite + 温暖手作风 admin panel.

## 启动

```bash
cd web-admin
npm install
npm run dev
```

Then open: http://localhost:5173

## Pages

| Path | Page |
|------|------|
| `/dashboard` | 仪表盘 |
| `/courses` | 课程管理 |
| `/orders` | 预约审核 |
| `/students` | 学员管理 |
| `/teachers` | 讲师管理 |
| `/locations` | 上课地点 |
| `/settings/banners` | 轮播图配置 |
